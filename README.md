## Overview

u-he Podolski is a free, streamlined synthesizer offering a single oscillator, multimode filter, and simple modulation section, delivering excellent sound quality in a minimal, approachable interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **u-he Podolski** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Single OSC** | One oscillator with sawtooth, pulse, and triangle waveforms plus sub |
| **Multimode Filter** | Low-pass, band-pass, and high-pass modes with resonance |
| **Mod Matrix** | Simple but flexible routing of envelope and LFO to key parameters |
| **Free Plugin** | Completely free for all platforms with no registration required |
